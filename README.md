# SkyCafe - Kafe Yönetim Sistemi

Modern bir web uygulaması ile Kafe ve Menu yönetim sistemi.

## Proje Özellikleri
- Kafe Yönetimi
- Menu Yönetimi
- Sipariş Sistemi
- User/Admin Paneli
- Responsive Design

## Teknoloji Stack
- **Frontend:** React, CSS3
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL/SQLite

## Klasör Yapısı
```
skycafe/
├── frontend/          # React uygulaması
├── backend/           # Node.js API
├── database/          # Veritabanı şemaları
└── README.md
```
